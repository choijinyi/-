# 최초 설정 안내 (사용자가 직접 하는 부분)

커넥터가 연결되지 않았을 때 사용자에게 안내할 절차이다. Claude가 대신 할 수 없는 단계(설치, 로그인, 커넥터 추가)이므로 순서대로 알려주고, 각 단계의 확인 방법으로 성공 여부를 점검한다.

준비물: 인터넷 연결, 힉스필드 계정(크레딧 필요), Claude 계정.

## 1. 블렌더 설치

- https://www.blender.org/download/ 에서 무료로 받는다. 계정 가입이나 결제는 필요 없다.
- 힉스필드 플러그인은 블렌더 4.2~5.1을 지원한다고 안내되어 있다. 범위를 벗어난 버전은 플러그인이 설치되지 않을 수 있다. 지원 범위는 바뀔 수 있으니 플러그인 페이지에서 확인한다.
- macOS는 Apple Silicon과 Intel 버전이 나뉜다.
- AI 생성은 힉스필드 서버에서 돌아가므로 고사양 GPU는 필요 없다. 프리비즈 렌더만 본인 컴퓨터 성능을 쓴다(EEVEE라 가볍다).

## 2. 힉스필드 블렌더 플러그인 설치

- https://higgsfield.ai/plugins/blender 에서 zip 파일을 받는다. **압축을 풀지 않는다.** 블렌더가 zip 그대로 설치한다.
- 방법 A: 블렌더를 켜고 zip을 창 위로 끌어다 놓는다.
- 방법 B: Edit ▸ Preferences ▸ Add-ons ▸ Install 에서 zip을 선택하고, 목록의 Higgsfield 체크박스를 켠다.
- 설치되면 3D 뷰포트 위에 힉스필드 바(floating bar)가 뜬다. Sign in을 눌러 브라우저에서 로그인하면 크레딧 잔액이 바에 표시된다.
- 바가 안 보이면 블렌더를 완전히 종료 후 재실행하고, 그래도 없으면 Add-ons에서 Higgsfield 체크 여부를 본다.

## 3. Higgsfield Bridge 커넥터 (블렌더 조작)

- Claude 설정 ▸ 커넥터 ▸ 커스텀 커넥터 추가
- 이름 `Higgsfield Bridge`, URL `https://bridge.higgsfield.ai/mcp`
- 저장 후 연결을 눌러 힉스필드 계정으로 승인한다.
- 확인: 블렌더를 켠 상태에서 "지금 블렌더에 연결돼 있어? 씬에 뭐가 있는지 알려줘"라고 물어 오브젝트 목록이 나오면 성공.
- Bridge는 블렌더가 실행 중이고 플러그인에 로그인되어 있어야 작동한다. 블렌더를 끄면 끊긴다.

## 4. Higgsfield MCP 커넥터 (이미지·영상 생성)

- 같은 화면에서 커넥터 추가. 이름 `Higgsfield`, URL `https://mcp.higgsfield.ai/mcp` (안내 페이지: https://higgsfield.ai/mcp)
- API 키는 필요 없고 로그인한 계정의 크레딧이 사용된다.
- 확인: "힉스필드 크레딧 잔액 알려줘"에 잔액이 나오면 성공.

## 환경별 유의점

Bridge는 사용자 컴퓨터의 블렌더와 통신한다. 클라우드에서 도는 세션은 커넥터를 통해 Bridge에 닿을 수 있어도 사용자 컴퓨터의 파일(렌더된 mp4)에는 직접 접근하지 못할 수 있다. 그 경우 업로드는 Bridge나 플러그인이 제공하는 경로로 처리하거나, 사용자에게 파일을 대화에 첨부해 달라고 요청한다.
